# Bank Transaction Analysis Using Python

## Project Overview
This project analyzes banking transaction data using Python to explore transaction patterns, summarize financial activity, and visualize key trends.

## Tools and Technologies
- Python
- Pandas — data loading, cleaning, and analysis
- Matplotlib — data visualization
- Google Colab — notebook execution

## Project Workflow
1. Loaded transaction data into a Pandas DataFrame.
2. Examined and analyzed the dataset.
3. Generated visualizations to explore transaction trends.
4. Interpreted the results to understand patterns in the available data.

## How to Run
1. Open `Bank_Transaction_Analysis_Project.ipynb` in Google Colab.
2. Upload the required CSV dataset when prompted by the notebook.
3. Run the notebook cells from top to bottom.
